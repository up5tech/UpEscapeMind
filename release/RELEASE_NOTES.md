# Release Notes — Up Escape Mind 1.0.0

**Version:** 1.0.0 (build 1)
**Date:** 2026-11-14
**Platforms:** Android, iOS

## Highlights

- **Prologue + Chapter 1 "The Clockmaker's Archive"** — 5 explorable areas
  (Entrance Hall, Clockmaker's Study, Workshop, Portrait Gallery, Sealed
  Observatory) with 19 puzzles across 8 puzzle families.
- **Fully offline** — all content, art, and saves are local; no account,
  no ads, no internet required.
- **Hint system** — 3 progressive hint levels per puzzle (nudge → clue →
  walkthrough), authored per puzzle, persisted, never blocking.
- **Journal** — every clue, note, and secret discovered is collected and
  reviewable, with chapter-completion star rating (completion, all
  puzzles, all secrets, no-walkthrough badge).
- **Inventory & combinations** — predefined item recipes only; invalid
  uses never consume items.
- **Vietnamese + English** — Vietnamese is the default locale; language
  can be overridden in Settings.
- **Accessibility** — semantics/tooltip support and reduced-motion
  handling.
